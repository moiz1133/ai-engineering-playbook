## Final Fixed Code
```python
def fibonacci(n, memo={}):
    if n < 0:
        raise ValueError("Input cannot be negative")  # Handle negative input
    if n in memo:  # Check for memoization
        return memo[n]
    if n == 0:
        return 0
    if n == 1:
        return 1
    memo[n] = fibonacci(n-1, memo) + fibonacci(n-2, memo)  # Store result in memo
    return memo[n]

def get_nth_fibonacci(n):
    if not isinstance(n, int):  # Check for integer type
        raise TypeError("Input must be an integer")  # Handle non-integer input
    return fibonacci(n)
```
